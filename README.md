# 🚀 Projeto Escolar em HTML e CSS

Projeto desenvolvido para uma atividade escolar utilizando apenas **HTML** e **CSS puro**. O site foi criado com foco em praticar estruturação de páginas, estilização, organização de conteúdo e desenvolvimento web básico.

## 📚 Objetivo

Aplicar conceitos fundamentais de desenvolvimento front-end, como:

* Estruturação de páginas com HTML
* Estilização com CSS
* Organização de layout
* Uso de cores e tipografia
* Criação de uma interface simples e funcional

## 💻 Tecnologias Utilizadas

* HTML5
* CSS3

## 🎯 Sobre o Projeto

Este projeto foi desenvolvido para fins educacionais, buscando aprimorar habilidades em desenvolvimento web e ganhar mais experiência na criação de sites utilizando tecnologias base da web.
